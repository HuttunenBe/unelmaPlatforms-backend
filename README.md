# 🐸 🚀 Unelma App - Ongoing 🚧

This app was made as a team project for a course at Business College Helsinki together with Unelma Platforms. The goal was to redesign Unelma Platforms and practice teamwork and full-stack web development by combining Next.js and headless Strapi into a single app. 

These are the backend files for Unelma Platforms app. You can find the frontend files [here](https://github.com/Space-Frogs-Inc/unelma-nextjs.git)
